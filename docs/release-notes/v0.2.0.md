# v0.2.0

Initial AWS module release for the BetterNAT Terraform surface reset.

## What Changed

- Wraps `betternat_aws_gateway`.
- Accepts common `terraform-aws-modules/vpc/aws` outputs:
  - `azs`
  - `public_subnets`
  - `private_route_table_ids`
  - `vpc_cidr_block`
- Defaults to AL2023 arm64 AMI lookup, `t4g.small`, Spot, active/standby
  capacity, stable shared EIP mode, Prometheus metrics, and rollback on
  destroy.
- Includes minimal, EKS/VPC module, stable EIP, non-stable EIP, and full VPC
  smoke examples.

## Validation

Run before publication:

```sh
terraform fmt -check -recursive
terraform init -backend=false
terraform validate
```

AWS smoke validation must use a disposable VPC and record cleanup evidence
before promotion.
