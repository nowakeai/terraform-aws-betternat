# v0.2.3

Patch release for generation-safe AWS gateway replacement.

## What Changed

- Raised the minimum BetterNAT provider version to `0.2.3`.
- Added `generation_ids`, exposing each physical gateway installation identity
  by availability zone.
- Replacement-required gateway changes are now visible during
  `terraform plan` through the provider instead of failing during an attempted
  in-place apply.
- Failed retries and stale Terraform deposed state are isolated from the
  current gateway generation.

## Compatibility

- Existing module inputs remain compatible.
- Existing gateway states receive a generation ID on their next physical
  replacement; new creates receive one immediately.
- External and retained EIP ownership behavior from v0.2.2 is unchanged.

## Validation

```sh
terraform fmt -check -recursive
terraform init -backend=false
terraform validate
```
